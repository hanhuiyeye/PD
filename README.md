# PRISMA-based Multi-Omics Review in Parkinson’s Disease

This repository contains visualization and analysis supporting the manuscript:

**Beyond Bacteria: A Multi-Omics View of the Gut–Brain Axis in Parkinson’s Disease.**

The repository includes publication-ready figures and visualizations derived from the curated dataset.

In addition, we provide an interactive Shiny application based on the PRISMA framework, incorporating both technical and scientific filtering steps. The app allows users to flexibly explore and modify filtering criteria in a user-friendly interface.

🔗 GitHub repository: https://github.com/euniceokk/prisma  
🔗 Shiny application: https://eok7.shinyapps.io/PRISMA/
